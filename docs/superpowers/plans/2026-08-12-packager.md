# Packager Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a `packager` CLI that previews a local `.deb` or `.rpm`, writes a PKGBUILD, runs `makepkg`, optionally `pacman -U`, and later reminds the user when extra or the AUR has a native package.

**Architecture:** A Rust CLI that shells out to `bsdtar`, `readelf`, `pkgfile`, `makepkg`, and `pacman`. Each spec unit is a `src/` module with a narrow public API. The PKGBUILD is the conversion artifact. Tests inject fakes for pacman/AUR; default `cargo test` never runs `pacman -U` and never needs root.

**Tech Stack:** Rust edition 2021, rustc 1.75+. Crates: `clap` (derive), `serde` + `serde_json`, `sha2`, `ureq` (blocking AUR RPC), `thiserror`, `tar` + `flate2` (fixture `.deb` writer). No async runtime. Binary crate + library crate (`packager`).

**Spec:** `docs/superpowers/specs/2026-08-12-packager-design.md`

## Global Constraints

- Temporary utility, not a package manager or AUR helper.
- `.deb` and `.rpm` → pacman only. No reverse conversion.
- Default verb: preview → convert → install. Skip install with `convert`. Stop after PKGBUILD with `scaffold`.
- Native extra/AUR match is a hard stop unless `--force`.
- Offline extra/AUR lookup is a hard stop unless `--force` (preview cannot claim “no native package”).
- Vendor scripts are never executed during convert. Packaged as `.install` only with `--allow-scripts`. No rewriting of `update-alternatives` / `update-rc.d` / `debconf`.
- Do not rewrite `/usr/lib/x86_64-linux-gnu` or `/usr/lib64` into Arch paths. Detect and warn only.
- Unmapped depends are omitted from the PKGBUILD `depends` array.
- Do not pass `-s` to `makepkg`.
- `forget` always asks about `pacman -R`; default is no; if remove fails, do not delete JSON.
- State: `~/.local/share/packager/installed/<pkgname>.json` written as the original user when invoked via sudo (`SUDO_USER`).
- PKGBUILD sets `packager = "packager <packager@local>"`.
- `pkgname`: lowercased, `_` → `-`. `pkgrel` is always `1`. `amd64`/`x86_64` → `x86_64`; `arm64`/`aarch64` → `aarch64`; anything else is wrong arch (stop).
- Workdir default: `~/.cache/packager/<pkgname>-<pkgver>/`. Never auto-delete.
- Root only for `pacman -U` and optional `pacman -R`. Stream pacman output. `--noconfirm` only with `--yes` on the action the user asked for.
- No vendor blobs in the repo. Generate tiny packages in the test harness.
- Default tests: no root, no `pacman -U`. `@system` tests are `--features system` and opt-in.
- Do not add debtap, alien, or fpm. Do not add tokio.

### Task 3: Parse `.deb` metadata

**Files:**
- Create: `src/source.rs`
- Create: `src/source/deb.rs`
- Modify: `src/lib.rs`

**Interfaces:**
- Consumes: `ident::Format`, `testpkg::write_deb`
- Produces:

```rust
#[derive(Clone, Debug)]
pub struct Script { pub name: String, pub body: String }

#[derive(Clone, Debug, Default)]
pub struct Package {
    pub format: ident::Format,
    pub path: PathBuf,
    pub raw_name: String,
    pub raw_version: String,
    pub epoch: String,
    pub raw_arch: String,
    pub depends: Vec<String>,
    pub provides: Vec<String>,
    pub conflicts: Vec<String>,
    pub replaces: Vec<String>,
    pub scripts: Vec<Script>,
    pub file_list: Vec<String>,
}

pub fn detect(path: &Path) -> Result<ident::Format>
pub fn parse_meta(path: &Path) -> Result<Package>
```

`detect`: suffix `.deb` / `.rpm` (case-insensitive). Else `Error` containing `"not a .deb/.rpm"`.

`parse_meta`: dispatch on `detect`. Deb: GNU ar → `control.tar.gz` → parse `Package`, `Version` (split epoch on first `:` so `1:2.0` → epoch=`1`, raw_version=`2.0`), `Architecture`, `Depends`/`Provides`/`Conflicts`/`Replaces` (split on `,`, strip `(…)` constraints and `[arch]`). Read `preinst`/`postinst`/`prerm`/`postrm` into `scripts`. Leave `file_list` empty. Rpm: return `Error::msg("rpm parse not implemented")` until Task 5.

### Task 6: ELF scan and layout warnings

**Files:**
- Create: `src/elfinfo.rs`
- Modify: `src/lib.rs`

**Interfaces:**
- Consumes: extracted tree path
- Produces:

```rust
pub struct Info {
    pub path: String,
    pub class: String,       // "ELF32" | "ELF64"
    pub interpreter: String,
    pub needed: Vec<String>,
}

pub fn scan(root: &Path) -> Result<Vec<Info>>
pub fn layout_warnings(file_list: &[String], infos: &[Info], host: ident::Arch) -> Vec<String>
```

`layout_warnings` (never rewrites paths):

- path contains `usr/lib/x86_64-linux-gnu` or `lib/x86_64-linux-gnu` → `"Debian multiarch path"`
- path contains `usr/lib64/` or `usr/lib64` as a prefix → `"Fedora lib64 path"`
- `class == "ELF32"` and `host == Arch::X86_64` → `"32-bit ELF on x86_64"`
- ELF with empty interpreter and non-empty `needed` → `"missing interpreter"`

`scan`: walk regular files, skip non-ELF; `readelf -h -d -l`. If `readelf` is missing, error contains `"readelf"`.

**Files:**
- Modify: `src/pm.rs` — `upgrade`, `remove`, `query`
- Create: `src/status.rs`
- Modify: `src/cli.rs`
- Modify: `src/lib.rs`

**Interfaces:**
- Consumes: `state`, `lookup`, `preview`, `build`
- Produces:
  - `pub fn upgrade(pkg_path: &Path, noconfirm: bool) -> Result<()>` — `pacman -U`, `--noconfirm` iff noconfirm. Stream stdio.
  - `pub fn remove(pkg: &str, noconfirm: bool) -> Result<()>` — `pacman -R` (not `-Rns`).
  - `pub fn query(pkg: &str) -> Result<Option<String>>` — `pacman -Q`, `None` if not installed.
  - `pub fn report(records: &[state::Record], q: &dyn Fn(&str) -> Result<Option<String>>, find: &dyn Fn(&[String]) -> Result<Vec<lookup::Hit>>) -> String`
    - Not installed → `not installed  →  forget`
    - Find `Err` → `lookup failed`, **never** `no native package`
    - extra/multilib hit → `  extra has <name> <ver>  →  replace: sudo pacman -S <name>` (use `Hit.repo`)
    - aur hit → `  aur has <name> <ver>  →  replace: <name> is in the AUR`
    - no hit, find ok → `  no native package`
  - CLI `install`: convert pipeline then `upgrade`. Success → `state::write`. Failure → no state, keep archive, exit 1.
  - CLI `status`: `state::list` + print `report`. Exit 0 even if lookup failed.
  - CLI `forget`: `state::read` (error if missing). Prompt `Also run pacman -R <pkg>? [y/N]` via hook `FORGET_REMOVE` (default stdin). Default no. `--yes` does **not** auto-yes this prompt. If yes: `remove`; on failure do not `state::delete`, exit 1. If no, or after successful remove: `state::delete`.

Hooks: `UPGRADE`, `REMOVE`, `QUERY`, `FORGET_REMOVE`.
